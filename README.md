# 🌿 MindSpace — Mood Journal

## 📌 Overview

**MindSpace — Mood Journal** is a simple and user-friendly application that helps users track their daily moods, thoughts, and emotions. It provides a safe digital space to reflect, understand patterns, and improve mental well-being over time.

---

## 🚀 Features

* 📝 **Daily Mood Logging** – Record your mood and thoughts easily
* 📊 **Mood Tracking** – Visualize how your mood changes over time
* 🔒 **Privacy Focused** – Your data stays safe and personal
* 🎯 **Simple UI** – Clean and minimal interface for better experience
* 📂 **Demo Mode** – Try the app with sample data

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Tools:** Git, GitHub
* **Package Managers:** Brew / Scoop (for easy setup)

---

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/mindspace.git
```

### 2️⃣ Open the project

Simply open the `index.html` file in your browser.

## 💡 How to Use

1. Open the app
2. Select your mood
3. Write your thoughts (optional)
4. Save your entry
5. Track your mood history
